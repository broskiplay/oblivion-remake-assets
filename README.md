# oblivion-remake-assets

Тайлы подложки и картинки из окон меток для интерактивной карты [The Elder Scrolls IV: Oblivion Remastered](https://broskiplay.ru/oblivion-remake-map/) (BroskiPlay). Раздаются через GitHub Pages.

- `tiles/<карта>/<z>/<x>/<y>.webp` и `tiles/<карта>/manifest.json` — список существующих тайлов
- `popups/<id>.webp` — картинки из окон меток (id — первые 12 символов UUID оригинала)
